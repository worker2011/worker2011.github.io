# 关于 SATA

你可能会注意到，积木鱼和 [OI Wiki](https://oi-wiki.org) 都采用了一个叫做 [SATA](https://github.com/zTrix/sata-license) 的~~逗逼~~小众协议。

::github{repo="zTrix/sata-license"}

:::note[注意！]
这里的 SATA 不是硬盘方面的，而是指一个叫 "The Star And Thank Author License" 的许可协议。
:::

这个协议基于著名的 MIT License，因此和 MIT 协议一样，极为自由（应该是符合 FSF/GNU 之类的组织所定义的“自由”的）、宽松。

而 SATA 协议的不同之处，从它的名字中很容易看出来——你要去给作者点 Star 并感谢项目作者！

具体来说，如果你使用了这个开源项目，而这个项目又使用了 SATA 协议，那么你需要给这个项目点个 Star （例如 SATA 协议本身），并遵循 MIT License。

当然，不是每个项目都在 GitHub 上，因此你也可以通过以下方式表达感谢：

1. 给这个项目挑 bug，让它变得更好
2. 给作者发感谢信（？）
3. 发篇文章（~~比如这篇~~）宣传一下该项目
4. 如果实在害羞的话，你也可以不说出来，心里默默的喊一句 ~~作者好闪，拜谢作者！~~ 感谢作者大大得无私奉献！即可

还是非常宽松、自由的。在此也提醒一下大家（尤其是各路企业），开源作者无私奉献、默默付出又不求回报，其实是一件很伟大的事情。希望大家多多支持、感谢开源作者，哪怕只是轻轻的点个 Star。~~Said no more counting dollars, We'll be counting stars.~~
